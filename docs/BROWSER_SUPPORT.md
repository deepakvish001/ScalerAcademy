# Browser support

Support the current and previous major versions of Chrome, Edge, Firefox, and Safari, plus responsive mobile layouts.

## Baseline

- Progressive enhancement for core schedule management
- Keyboard-operable forms and actions
- Visible focus and readable validation errors
- No reliance on hover-only interaction
- Automated system tests for the primary workflow

Review the Browserslist configuration when usage data or product requirements change. Document any deliberate unsupported behaviour.
