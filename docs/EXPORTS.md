# Interview exports

Supported formats may include JSON, CSV, and iCalendar.

## Requirements

- Apply the same authorisation as the web interface.
- Export only requested fields.
- Use UTC or include an explicit time zone.
- Escape spreadsheet-formula prefixes in CSV values.
- Stream large exports instead of loading every row.
- Record who requested a bulk export.

Exports containing email addresses are personal data and require controlled retention.
