# User roles

## Roles

| Role | Intended access |
| --- | --- |
| Student | View own interviews and availability |
| Interviewer | View assigned interviews and availability |
| Coordinator | Create and reschedule interviews |
| Administrator | Manage configuration and audit operations |

Permissions must be checked on the server for every record. A hidden link is not authorisation. Default-deny new actions until a role is explicitly granted access.
